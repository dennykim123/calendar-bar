Calendar Bar

Privacy Policy

Last updated 25 July 2026

Calendar Bar collects nothing. There is no account, no analytics, and the app makes no network requests at all.

The app

Calendar Bar runs entirely on your Mac. Specifically, it:

  • makes no network requests — it has no server to talk to;
  • has no accounts and no sign-in;
  • contains no analytics, telemetry, crash reporting, or advertising code;
  • never requests access to your calendars, contacts, location, photos, microphone, or camera.

Your preferences (menu bar format, icon shape, highlight colour, language, appearance, first day of week) are stored locally in macOS user defaults and never leave your Mac. A supporter code, if you enter one, is verified locally on your Mac — it is not sent anywhere.

This website

This site is a set of static pages hosted on GitHub Pages. It sets no cookies and runs no analytics. One preference — your light/dark choice — is kept in your browser's local storage and is never transmitted. As with any web host, GitHub processes standard server request data (such as IP address) to deliver the pages; see GitHub's own privacy statement for details. Downloads are served from GitHub Releases.

Supporting the app

Supporting Calendar Bar is entirely optional. If you pay by card, the transaction is handled by Paddle.com Market Limited as the merchant of record; Paddle receives your payment and billing details under its own privacy policy, and we only see what is needed to send you a supporter code (your email address and the fact that a purchase was made). If you send a gift card by email, we receive only the email you send.

Email

If you write to us, we keep your message so we can reply. We do not add you to any mailing list, and there is none to add you to.

Children

Calendar Bar is a general-purpose utility and is not directed at children. Because it collects no data, it collects none from children either.

Your rights

We hold no personal data about you beyond any email you have sent us. If you would like that correspondence deleted, ask and it will be deleted.

Changes

If this policy changes, the updated date at the top of this page changes with it. Material changes will be noted on this page.
